02
템플릿

템플릿은 세 가지만 보고 고릅니다

오래 고르지 않습니다. 지난 차시에 본 무료 템플릿 중 하나를 써도 됩니다.

  1. 사진이 크게 들어가는가첫 화면에 렌더 한 장이 화면을 채우는 구성
  2. 메뉴가 단순한가메뉴 4–5개 이하. 6개 섹션과 그대로 맞출 수 있는지
  3. 무료인가Free 표시 확인. 유료 템플릿은 구매가 필요

03
구조

한 페이지를 위에서 아래로 걷게 만듭니다

판넬 QR로 들어온 사람은 휴대폰으로 스크롤만 합니다. 6주차의 '스크롤은 곧 걷기'를 그대로 적용해, 영상과 컨셉으로 들어가 공간을 둘러보고 About에서 나오게 합니다.

섹션넣을 것분량자주 하는 실수
Hero대표 렌더, 작품명, 한 줄 컨셉, 이름이미지 1 · 글 2줄글이 사진의 중요한 부분을 가림
VideoYouTube 영상, 러닝타임영상 1자동재생 켜 둠
Concept컨셉 문장, 컨셉 · 동선 다이어그램글 3–4줄 · 이미지 1–2설명이 너무 김
Drawing평면도, 단면도이미지 2–4선이 가늘어 휴대폰에서 안 보임
Render공간 순서대로 렌더 + 짧은 캡션이미지 6–12같은 앵글 반복
About자기소개, 연락처, 사용한 도구글 3줄 · 링크 2–3AI 도구 표기 누락
쓰지 않는 템플릿 섹션(Testimonials, Pricing, Blog 등)은 숨기지 말고 삭제합니다. 메뉴 링크는 다른 페이지가 아니라 같은 페이지의 섹션으로 연결합니다. 프로젝트가 두 개 이상인 학생만 상세 페이지를 추가합니다.
04
브랜드 적용

색과 글꼴은 스타일로 한 번에 바꿉니다

요소 하나씩 바꾸지 않습니다. 템플릿은 색과 글꼴을 스타일로 묶어 두었기 때문에 스타일만 바꾸면 사이트 전체가 바뀝니다.

  1. Assets 패널 열기왼쪽 패널에서 Colors · Text 스타일 목록 확인
  2. Color Style 교체주조 · 보조 · 강조 색을 브랜드 시트 HEX로. 비율은 60 · 30 · 10
  3. Text Style 교체제목 · 본문 스타일의 글꼴을 브랜드 폰트 2종으로
  4. 끝까지 스크롤해 확인스타일을 쓰는 모든 요소가 함께 바뀌었는지
강조색은 버튼 · 링크 · 숫자에만 씁니다. 브랜드 폰트가 목록에 없으면 Pretendard, Noto Sans KR처럼 Google Fonts에 있는 한글 글꼴로 대신하고 브랜드 시트도 같은 이름으로 고칩니다. 영상 자막, 숏폼과 같은 색인지가 14주차 브랜드 점검 항목입니다.
05
내용 채우기

이미지와 글은 이렇게 바꿉니다

메뉴 위치와 이름은 Framer 업데이트로 바뀔 수 있습니다. 수업 당일 화면을 같이 보며 진행합니다.

이미지

이미지 선택 → 오른쪽 속성 패널의 Fill에서 이미지 교체 → Fit · Fill로 잘림 조정

글

글 상자 더블클릭 → 입력 → 바깥 클릭. 스타일은 Text Style 유지

섹션

왼쪽 Layers에서 선택 → 복제 Ctrl/⌘ + D · 삭제 Delete · 되돌리기 Ctrl/⌘ + Z

영상은 YouTube로 올리고 연결만 합니다
  1. YouTube 업로드공개 범위 '일부 공개', 퍼가기 허용 확인
  2. Framer에 삽입Insert의 Media에서 YouTube 선택 → 영상 주소 붙여넣기
  3. 자동재생 끄기Autoplay 해제. 5분 영상 파일을 사이트에 직접 올리면 로딩 5초를 지킬 수 없습니다
자동 저장 ≠ 게시. 작업은 자동 저장되지만, Publish를 누르기 전까지 방문자에게는 보이지 않습니다.
06
휴대폰 점검

PC에서 끝난 게 아닙니다. 휴대폰이 기준입니다

심사위원과 채용담당자는 판넬 QR을 휴대폰으로 찍어 들어옵니다. 화면 상단의 Breakpoint를 바꿔 가며 크기별로 고칩니다. 한 크기에서 고친 글자 크기가 다른 크기에는 적용되지 않을 수 있습니다.

Desktop
Tablet
Phone
  1. 제목이 두 줄 넘게 꺾이지 않는다
  2. Hero 사진의 중심이 잘리지 않는다
  3. 도면 선과 글씨가 읽힌다
  4. 섹션 순서가 PC와 같다
  5. 메뉴가 햄버거 버튼으로 열린다
마지막 확인은 반드시 내 휴대폰으로 미리보기 링크를 열어서 합니다.

08
게시

Publish를 눌러야 세상에 나갑니다

  1. Publish 클릭오른쪽 위 버튼
  2. 주소 이름 정하기영문 이름 또는 작품명
  3. 게시 완료발급된 링크를 휴대폰으로 열어 확인
  4. 고치면 다시 Publish누르지 않으면 QR로 들어온 사람은 이전 버전을 봅니다
무료 플랜으로 충분합니다. 무료 게시는 Framer 주소(예: 이름.framer.website 형식)와 'Made in Framer' 배지가 붙습니다. 개인 도메인 연결과 배지 제거는 유료 플랜이 필요하며 이 수업의 필수 조건이 아닙니다. 주소 형식과 가격은 바뀔 수 있으니 게시 화면의 안내를 기준으로 합니다.
09
QR 코드

주소를 QR로 바꿔 판넬에 붙입니다

QR 생성 사이트는 광고가 많고, 일부는 나중에 유료로 바뀌어 QR이 작동하지 않게 만듭니다. Chrome에 있는 기능을 씁니다.

  1. Chrome으로 사이트 열기게시된 주소로 접속
  2. QR 코드 만들기주소창의 공유 메뉴 → QR 코드 만들기 → 다운로드
  3. 판넬에 배치가로 3cm 이상, 주변에 여백
  4. 찍어 보기출력 후 휴대폰 3대 이상으로 인식 확인

문제 해결

자주 막히는 곳

고쳤는데 사이트에 안 보여요

Publish를 다시 누르지 않았습니다. 다시 게시한 뒤 새로고침하세요. 질문의 절반이 이것입니다.

이미지가 안 올라가요

용량이 큽니다. 가로 2400px · 1MB 안팎으로 줄여서 다시 올리세요.

휴대폰에서 글자가 넘쳐요

Phone 화면에서 해당 글의 크기를 따로 줄입니다. Desktop에서 고친 값은 Phone에 그대로 적용되지 않을 수 있습니다.

영상이 재생되지 않아요

YouTube 공개 범위가 '일부 공개'인지, 퍼가기 허용이 켜져 있는지 확인하세요.

카톡 미리보기가 템플릿 그대로예요

Site Settings에서 소셜 이미지와 설명을 바꾸고 다시 게시하세요. 카카오톡 쪽 반영에는 시간이 걸릴 수 있습니다.

버튼 이름이 이 안내와 달라요

Framer 업데이트로 메뉴 이름이 바뀌었을 수 있습니다. 수업 중 화면을 기준으로 질문하세요.
