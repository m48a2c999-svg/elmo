# 웹 포트폴리오 구축·게시 워크북 (학생용 · 검토용)

2026학년도 2학기 · 호서대학교 실내건축학과 졸업연구 · Framer로 졸업작품 사이트를 만들고 공개 주소로 올리는 단계별 안내

작성 2026-10-18 · Framer 화면의 메뉴 이름과 무료 플랜 조건은 업데이트로 바뀔 수 있으므로 수업 당일 화면을 기준으로 합니다.

---

## 0. 완성 기준

이 표의 모든 항목을 갖추면 완성입니다.

| 구분 | 기준 |
| --- | --- |
| 필수 섹션 6개 | Hero · Video · Concept · Drawing · Render · About |
| 공개 URL | 로그인하지 않은 사람이 휴대폰으로 열 수 있는 주소 |
| 반응형 | Desktop · Tablet · Phone 세 화면에서 읽힘 |
| 영상 | 자동재생 끔 |
| 속도 | 휴대폰에서 첫 화면이 5초 안에 뜸 |
| QR 코드 | 판넬에 붙일 PNG 1개, 휴대폰 3대 이상에서 인식 |

**제출물:** 공개 URL · QR 이미지(PNG) · PC 첫 화면 캡처 1장 · 휴대폰 첫 화면 캡처 1장

---

## 1단계. 자료 모으기 (작업 전)

한 폴더에 아래 여섯 가지를 모읍니다.

- [ ] 브랜드 시트: 컬러 3색 HEX 코드, 폰트 2종 이름, 포지셔닝 한 문장
- [ ] 대표 이미지 1장 (Hero용 가로 렌더)
- [ ] 렌더 6–12장 (공간 순서대로 번호)
- [ ] 도면 2–4장 (평면 · 단면 · 다이어그램을 이미지로 내보내기, 선 두께를 평소보다 굵게)
- [ ] 5분 영상의 YouTube 링크
- [ ] About 문장 2–3줄 + 연락처(이메일, 작품용 인스타그램)

### 이미지 규격

| 항목 | 기준 |
| --- | --- |
| 크기 | 가로 2400px 이하 |
| 용량 | 한 장 1MB 안팎 |
| 형식 | JPG 또는 WebP (PNG는 도면 · 로고만) |
| 파일 이름 | 영문 소문자 · 숫자 · 밑줄만. 예: 01_hero.jpg, 02_lobby.jpg |

클로드 코드에 이렇게 요청하면 한 번에 처리됩니다.

> 이 폴더의 이미지를 가로 2400px로 줄이고 WebP로 변환해줘. 파일 이름은 01_, 02_ 순서 번호를 붙여 영문 소문자로 바꿔줘. 원본은 그대로 두고 새 폴더에 저장해줘.

### 영상 올리기

1. YouTube에 5분 영상 업로드
2. 공개 범위: **일부 공개** (링크를 아는 사람만 시청)
3. 고급 설정에서 **퍼가기 허용** 확인
4. 영상 주소 복사

---

## 2단계. 템플릿 고르고 복제하기

세 가지만 확인합니다.

1. 첫 화면에 사진이 크게 들어가는가
2. 메뉴가 4–5개 이하로 단순한가
3. 무료(Free) 템플릿인가

지난 차시에 본 무료 템플릿: **Forma Interior**(공간 사진을 크게) · **VOLUM**(건축 사진 + 절제된 메뉴) · **ARCHIOR**(여러 프로젝트 갤러리)

**복제:** 템플릿 페이지에서 Remix(복제) → 내 프로젝트 목록에 복사본이 생깁니다. 원본은 바뀌지 않습니다.

- [ ] 템플릿 복제 완료
- [ ] 프로젝트 이름을 「작품명_이름」으로 변경

---

## 3단계. 구조 잡기

홈 한 페이지에 6개 섹션을 위에서 아래로 쌓습니다. QR로 들어온 사람은 휴대폰으로 스크롤만 하기 때문입니다.

| 순서 | 섹션 | 넣을 것 | 분량 | 자주 하는 실수 |
| --- | --- | --- | --- | --- |
| 1 | Hero | 대표 렌더, 작품명, 한 줄 컨셉, 이름 | 이미지 1 · 글 2줄 | 글이 사진의 중요한 부분을 가림 |
| 2 | Video | YouTube 영상, 러닝타임 | 영상 1 | 자동재생 켜 둠 |
| 3 | Concept | 컨셉 문장, 컨셉 · 동선 다이어그램 | 글 3–4줄 · 이미지 1–2 | 설명이 너무 김 |
| 4 | Drawing | 평면도, 단면도 | 이미지 2–4 | 선이 가늘어 휴대폰에서 안 보임 |
| 5 | Render | 공간 순서대로 렌더 + 짧은 캡션 | 이미지 6–12 | 같은 앵글 반복 |
| 6 | About | 자기소개, 연락처, 사용한 도구 | 글 3줄 · 링크 2–3 | AI 도구 표기 누락 |

- [ ] 쓰지 않는 템플릿 섹션(Testimonials, Pricing, Blog 등)은 숨기지 말고 삭제
- [ ] 다른 페이지(About, Projects 등)는 프로젝트가 하나라면 삭제하고 홈에 통합
- [ ] 메뉴 링크를 같은 페이지의 섹션으로 연결

---

## 4단계. 브랜드 적용 (색 · 글꼴)

요소 하나씩 바꾸지 말고 **스타일**을 바꿉니다.

1. 왼쪽 Assets 패널에서 Colors · Text 스타일 목록 확인
2. Color Style: 템플릿의 주조 · 보조 · 강조 색을 브랜드 시트 HEX로 수정 (비율 60 · 30 · 10)
3. Text Style: 제목 · 본문 스타일의 글꼴을 브랜드 폰트 2종으로 변경
4. 페이지를 끝까지 스크롤하며 모든 요소가 함께 바뀌었는지 확인

- 강조색은 버튼 · 링크 · 숫자에만 사용합니다.
- 브랜드 폰트가 목록에 없으면 Google Fonts에 있는 한글 글꼴(Pretendard, Noto Sans KR 등)로 대신하고, 브랜드 시트에도 같은 이름으로 고칩니다.

## 5단계. 내용 채우기

| 바꿀 것 | 방법 |
| --- | --- |
| 이미지 | 이미지 선택 → 오른쪽 속성 패널의 Fill에서 이미지 교체 → Fit · Fill로 잘림 조정 |
| 글 | 글 상자 더블클릭 → 입력 → 바깥 클릭. 스타일은 Text Style 유지 |
| 섹션 복제 · 삭제 | 왼쪽 Layers에서 선택 → 복제 Ctrl/⌘ + D · 삭제 Delete |
| 되돌리기 | Ctrl/⌘ + Z |
| 영상 | Insert의 Media에서 YouTube 선택 → 영상 주소 붙여넣기 → **Autoplay 해제** |

**작업은 자동 저장되지만, Publish를 누르기 전까지 방문자에게는 보이지 않습니다.**

- [ ] Hero
- [ ] Video (자동재생 끔)
- [ ] Concept
- [ ] Drawing
- [ ] Render
- [ ] About (사용한 AI 도구 표기)
- [ ] 페이지 맨 아래 푸터까지 템플릿 샘플 글 · 사진이 남아 있지 않음

---

## 6단계. 휴대폰 화면 점검

화면 상단의 Breakpoint(Desktop · Tablet · Phone)를 바꿔 가며 크기별로 고칩니다. 한 크기에서 고친 글자 크기가 다른 크기에는 적용되지 않을 수 있습니다.

Phone 화면 확인 항목

- [ ] 제목이 두 줄 넘게 꺾이지 않는다
- [ ] Hero 사진의 중심이 잘리지 않는다
- [ ] 도면 선과 글씨가 읽힌다
- [ ] 섹션 순서가 PC와 같다
- [ ] 메뉴가 햄버거 버튼으로 열린다
- [ ] 미리보기 링크를 **내 휴대폰으로** 열어 확인했다

---

## 7단계. 사이트 정보 입력 (Site Settings)

빼먹으면 카카오톡으로 링크를 보냈을 때 템플릿 제작자의 이름과 샘플 사진이 뜹니다.

| 항목 | 입력할 것 | 보이는 곳 |
| --- | --- | --- |
| 사이트 제목 | 작품명 \| 이름 | 브라우저 탭, 검색 결과 |
| 설명 | 한 줄 컨셉 | 카카오톡 · 검색 미리보기 |
| 파비콘 | 정사각 PNG (브랜드 시그니처) | 브라우저 탭 아이콘 |
| 소셜 이미지 | 1200×630 대표 렌더 | 링크 공유 미리보기 |

권장 규격은 Framer 화면의 안내를 우선합니다.

---

## 8단계. 게시하기 (Publish)

1. 오른쪽 위 **Publish** 클릭
2. 주소 이름 입력 (영문 이름 또는 작품명)
3. 게시 완료 후 발급된 링크를 휴대폰으로 열어 확인
4. **수정할 때마다 다시 Publish.** 누르지 않으면 방문자는 이전 버전을 봅니다.

**무료 플랜으로 충분합니다.** 무료 게시는 Framer 주소(예: 이름.framer.website 형식)와 'Made in Framer' 배지가 붙습니다. 개인 도메인 연결과 배지 제거는 유료 플랜이 필요하며 이 수업의 필수 조건이 아닙니다. 주소 형식과 가격은 바뀔 수 있으니 게시 화면의 안내를 기준으로 합니다.

---

## 9단계. QR 코드 만들기

QR 생성 사이트는 광고가 많고, 일부는 나중에 유료로 바뀌어 QR이 작동하지 않게 만듭니다. Chrome 기능을 사용합니다.

1. 게시된 사이트를 Chrome으로 열기
2. 주소창의 공유 메뉴 → **QR 코드 만들기** → 다운로드
3. 판넬에 가로 3cm 이상, 주변에 여백을 두고 배치
4. 출력 후 휴대폰 3대 이상으로 인식 확인

---

## 10단계. 제출 전 체크리스트

- [ ] 6개 섹션이 순서대로 있다
- [ ] 템플릿 샘플 글 · 사진이 하나도 남지 않았다
- [ ] 브랜드 컬러 3색 · 폰트 2종 안에 있다
- [ ] 영상 자동재생이 꺼져 있다
- [ ] 휴대폰에서 첫 화면이 5초 안에 뜬다
- [ ] 제목 · 설명 · 파비콘 · 소셜 이미지를 바꿨다
- [ ] 마지막 수정 후 다시 Publish 했다
- [ ] QR이 휴대폰 3대에서 인식된다
- [ ] About에 사용한 AI 도구를 적었다

## 자주 막히는 곳

| 증상 | 원인과 해결 |
| --- | --- |
| 고쳤는데 사이트에 안 보인다 | Publish를 다시 누르지 않았다. 다시 게시 후 새로고침 |
| 이미지가 안 올라간다 | 용량이 크다. 가로 2400px · 1MB 안팎으로 줄여서 다시 |
| 휴대폰에서 글자가 넘친다 | Phone 화면에서 해당 글의 크기를 따로 줄인다 |
| 영상이 재생되지 않는다 | YouTube 공개 범위(일부 공개)와 퍼가기 허용 확인 |
| 카톡 미리보기가 템플릿 그대로다 | 소셜 이미지 · 설명 교체 후 재게시. 카카오톡 쪽 반영에 시간이 걸릴 수 있음 |
| 템플릿 버튼 이름이 안내와 다르다 | Framer 업데이트로 메뉴 이름이 바뀌었을 수 있음. 수업 중 화면을 기준으로 질문 |
